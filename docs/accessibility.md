# Tilgjengelighet

Prototypen demonstrerer noen få tekniske prinsipper og er ikke en ferdig tilgjengelighetsgodkjenning.

## Demonstrert

- tastaturbetjening uten mus
- synlig fokusmarkering
- semantiske HTML-elementer
- enkel brytersimulering med tastetrykk
- nettleserbasert talesyntese
- separat elevmodus med redusert kompleksitet

## Skal verifiseres i prosjektet

- NVDA + relevant leselist
- Tash-brytere / SwitchSend
- samspill mellom innebygd tale og skjermleser
- elevens faktiske autentiseringsflyt
- konkrete akseptansekriterier sammen med Statped
